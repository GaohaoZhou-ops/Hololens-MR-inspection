连接说明与画面调试
  1. 保持设备唤醒并连接同一 Wi-Fi。在头显开发者选项中开启 Device Portal。
  2. 首次使用先登录。“设备门户登录”会打开官方登录页。完成登录和证书确认后，回到本页点“开始直播”；视频直接在上方播放。
  3. 在 App 内合拢一次。本页显示拍照提示，头显拍一张并保存，随后画面自动恢复。保持合拢不会连拍。
  4. 按需切换画质。修改选项后点“重新开始直播”。让头显拍到下方参考时钟，可将画面中的时间与本机时间比较，估算延迟。

画质菜单为官方接口的标称档位，不代表已测得的帧率或延迟。系统合成视角与眼睛看到的视角可能不同，不能单凭直播判断空间标签精度。

画面无法播放时

先点击“设备门户登录”，确认设备地址并完成登录、证书提示，再回到本页重新开始。若浏览器请求访问本地网络，请允许本页连接头显。如果设备门户也打不开，检查休眠、IP 变化及 Wi-Fi 是否允许设备互访。

直播由浏览器直接连接头显；照片接收、历史工作和轨迹仍由电脑端服务处理。本页面只记住设备地址和画质选项。
